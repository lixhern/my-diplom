# Название проекта
Программное средство для автоматической сегментации области печени и гемангиомы на МРТ изображениях с использованием нейросетевой модели U-Net.
## 🛠 Требования
* Python 3.11.x (обязательно)
* Windows 10/11
* NVIDIA GPU (рекомендуется для CUDA)
## 📂 Данные
- `rootData/Hemangiomas/` — исходные МРТ изображения
- `project-11-at-2024-09-13-14-37-2642aa96/` — разметка (маски)
- `project-11-at-2024-09-13-14-37-2642aa96.json` — аннотации датасета
## 📂 Результаты
- `dataset/` — сформированный датасет для обучения
- `visualisation/` — результаты предсказаний модели (PNG изображения)
- `unet_best.pth` — сохранённая лучшая модель
## 📄 Основные файлы
- `data_processing.py` — формирование датасета из исходных данных
- `model.py` — обучение U-Net модели и сохранение весов
- `metrics.py` — расчёт метрик качества (Dice, IoU и др.)
- `predict.py` — генерация предсказаний и визуализация результатов
- `streamlit.py` — пользовательский интерфейс
## 📜 Скрипты запуска
- `install.bat` — автоматическая установка виртуального окружения и всех зависимостей проекта (включая PyTorch с поддержкой CUDA)
- `start.bat` — запуск пользовательского интерфейса (Streamlit) и основных функций проекта
## 🚀 Как запустить
1. Клонируйте репозиторий:
git clone https://github.com/lixhern/my-diplom.git
2. Переход в папку проекта: cd my-diplom
3. Созданйте виртуальное окружение: python -m venv .venv
4. Установка зависимсотей: install.bat
5. Запустите проект:
   - двойным кликом по start.bat
   - либо в терминале ./start.bat
6. В запущенной консоли:
   - можно ввести email (не обязательно)
   - либо нажать Enter, чтобы пропустить шаг
